NGAME-CM — Directors and agents

Companion to NGAME_CM_ROADMAP.md · 22 Sep 2026 · Same detector as Classic

Roles are not greatly expanded. The picture of the books, the CPI / z / SCPI math, and the FRP write-up are the same agents. What CM added sits outside that roster: who starts the day, the lock, the written log, and the lamp.

NGAME-CM is automated ongoing snapshot surveillance. It notifies the FRP of meaningfully anomalous ledger-profile events. It does not see every QuickBooks save, does not ingest Audit Log, and does not perform a formal audit.

The short answer

QuestionAnswer
Are there new detector agents in CM?No.
Did existing agents gain new fraud logic?No. Do not retune μ/σ or the 30-day window to ship a scheduler.
What changed?Who starts a run (scheduler, not the FRP click), plus lock, journal, and lamp. Those are orchestration. They are not directors or agents.
Who sequences the daily agents in production?The same two flow managers as Classic.

A director or flow manager, in this document, is a sequencer: it calls the specialized agents in order. It does not compute CPI and it does not talk to the FRP.

An agent, in this document, is one owned step in that sequence (pull the books, score CPI, write a matrix column, warn management, and so on).

Wiring note — two stacks

Today the scheduler and the dashboard do not start the same child process.

StarterChildAgent stack
Schedulerngame_dual_mode.pyEnhanced Phase 1 Director + Phase 2 Director + dual-mode’s own shorter tails
Dashboard override / training and fraud launchersFlow managersFull Phase I or Phase II agent tables above

Until the scheduler starts the same scripts the dashboard uses, “CM uses the same agents” is true for the override path and only partly true for the clock path.

What to tell a customer

The same specialists still take the picture of the books and score it. Continuous monitoring did not add a new fraud brain. What we added is a clock, a one-at-a-time rule, a written log, and a status light, so the FRP does not have to click every day.
